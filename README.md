## 换图

- 单张：覆盖 `img/<品类>/00.jpg` 与缩略图 `t-00.jpg`
- 整组：替换 `img/<品类>/` 目录，再改对应 `c/<品类>.html` 里的 `src` 与 `data-full`
- 批量：把新图放进一个文件夹，改 `_tools/picks.json` 里的路径后运行 `python _tools/build_site.py`，自动裁切、压缩、生成缩略图和全部页面

## 上线（长期可访问）

| 方案 | 操作 | 时间 | 是否需要备案 |
|---|---|---|---|
| Cloudflare Pages / Vercel | 拖入 `tengbian-site` 文件夹 | 10 分钟 | 不需要（但国内访问偏慢） |
| 阿里云 OSS + CDN | 上传 Bucket，开静态托管 | 30 分钟 | 域名需 ICP 备案 |
| 轻量应用服务器 + Nginx | 放 `/var/www`，配 Nginx | 1 小时 | 域名需 ICP 备案 |

国内服务器必须先完成 ICP 备案（7–20 个工作日）再解析域名，顺序不能反。

## 后台（登录改内容）

三种做法，按省事程度排：

1. **Pages CMS / Decap CMS**（免费，推荐起步）：内容存 GitHub，登录后网页里改文字、传图，自动重新发布。需要先有 GitHub 账号。
2. **我做一个轻量管理端**：Node + 密码登录，能改文案、传图、排序，部署在同一台服务器。需要一台服务器，成本约 100–300 元/年。
3. **WordPress**：后台最成熟、插件最多，但要把现在这套设计改成 WP 主题，工作量大，且同样需要服务器 + 备案。
